# Publication provenance

This repository starts with a reviewed source snapshot of pFlow for Mac 0.3.4 and Windows 0.1.8. The earlier development repository and its commit history remain private. This avoids publishing personal commit metadata or development artifacts while retaining the original code and license notices.

The upstream Yap project is https://github.com/FrigadeHQ/yap. The full MIT notice is in LICENSE. The public snapshot excludes upstream demonstration media and all user data, device access files, logs, build symbols, and private working notes.

The Mac testing download is ad-hoc signed without a personal developer certificate. The Windows download is built without personal source paths or debug symbols. Neither download is a notarized/Authenticode-signed production release.
