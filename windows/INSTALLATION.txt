pFlow by Pesh: Windows and Mac installation

WINDOWS: x64 (Intel/AMD), ARM64, or x86 (32-bit)

Use pFlow-Setup-0.1.24-testing.exe. One file installs the right build (x64,
ARM64 or x86) for your Windows user account. No administrator password, no
.NET installation and no architecture choice is needed.
Windows 11 and Windows 10 version 1607 or later are required. Older Windows
cannot run the included .NET 10 runtime. Microsoft's supported Windows 10
editions are LTSC/Enterprise; Windows 10/older hardware is not fully tested here.

1. Download pFlow-Setup-0.1.24-testing.exe from https://github.com/PESHian/pFlow/releases
2. Double-click it. This test build is not signed, so Windows may show
   "Windows protected your PC": click "More info", then "Run anyway".
3. If pFlow is already running, Setup asks to close it, then asks whether you
   want a desktop shortcut. It unpacks, checks the files, installs for your
   account, adds pFlow by Pesh to the Start menu, and opens pFlow.
4. pFlow's speaking-pig icon appears in the tray (possibly under the up-arrow).
   Open Settings there and choose your language.
5. Under Shortcut, choose Press a key, then press and release one key. Right Alt,
   either Ctrl, Menu/App, other F keys, and detectable vehicle buttons can be used.
   Common choices remain in the picker. The chosen key records when used alone
   instead of typing or opening its usual action. Ordinary shortcuts still work.
   Escape stays available to cancel. Right Windows is the unchanged default.
   Settings > Updates shows one line with your version, architecture and speech
   engine (for example "x64, fast speech engine (AVX2)"): quote it when reporting.
6. Allow desktop microphone access in Windows Settings > Privacy & security >
   Microphone. On Windows 10, this is Settings > Privacy > Microphone.
7. Open Notepad. Hold your chosen key, speak, and release to insert. Double-tap
   for continuous recording; tap to stop. Escape cancels. Left Windows stays free
   unless you choose it as your activation key.

Whisper, its verified speech model, and the .NET runtime are included. Recording
and transcription work offline. A separate optional 1.1 GB text model can be
downloaded in pFlow Settings on 64-bit Windows for AI cleanup and report sections.
That optional AI feature is unavailable on 32-bit Windows; dictation, basic
cleanup, dictionary, and full-narrative templates remain available.

The app is unsigned. Updates preserve settings and History outside the app.
The installer retains a previous application folder. Never run a single EXE
copied out of the package without its accompanying files.

MAC: Apple Silicon, macOS 27 or later

1. Quit pFlow before updating.
2. Download pFlow-Mac-0.3.5-testing.dmg from the same GitHub releases page.
3. Open the DMG and drag pFlow by Pesh into Applications. Open pFlow there.
4. This testing build is not notarized. If blocked, follow Apple's Open Anyway
   steps after checking the download: https://support.apple.com/en-us/102445
5. Grant Microphone, Accessibility, Automation, and Speech Recognition permissions
   when requested. Download the verified Whisper model in pFlow Settings if needed.
6. Open TextEdit. Hold Right Command, speak, and release to insert. Double-tap
   for continuous recording; tap again to stop.

Use only one recorder at a time. Turn Mac dictation off before recording in a
Windows VM; Right Command may map to Right Windows in the VM.

These are testing releases. Read the release notes for the exact machines and
behaviors tested. Architecture support does not promise identical speed on all PCs.

Fn works only if the keyboard sends it as a usable keyboard event to Windows.
Some Fn buttons are handled inside the keyboard or use a separate system-button
interface. The picker times out clearly when it receives no usable key.

SETTINGS AND PROCESSING TIME

On/off controls show their state in words and with a moving thumb. Settings
shows the last dictation time, split into Speech, AI cleanup, Report, and
Insertion when those stages ran. The timing record has no dictated words.
AI cleanup remains optional and keeps your saved choice.

FUTURE UPDATES

In either app, choose Check for updates from its tray/menu bar or Settings,
then Install and restart. If your app has no Check for updates button, install a
current build once using the steps above. Windows 0.1.11 and Mac 0.3.5 or later
include the updater. Published GitHub binary releases supply updates; source
commits alone do not. Checks are on request.
